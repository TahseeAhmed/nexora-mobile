# Nexora Mobile
A premium, animated smartphone e-commerce homepage built with React (Vite).
UI library: Material UI (MUI), with Framer Motion for animations.
Install: `npm install`
Run: `npm run dev` (open the local URL shown), build: `npm run build`
Benefit of MUI: it saved us from manually building and styling reusable components such as buttons, cards, navigation bars, and responsive layouts.
